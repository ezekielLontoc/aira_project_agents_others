# ADR-0012: Enterprise Application Factory Foundation

## Status

Accepted

## Date

2026-06-11

## Context

AIRA has completed the governed MVP foundation and server-IP runtime hardening. The next platform need is to evolve into a governed application factory capable of helping build enterprise applications from blueprints.

## Decision

Add Milestone 16: Enterprise Application Factory Foundation.

The foundation introduces:

- Application Factory Agent Orchestrator
- Blueprint-to-Code Generator
- Project Template Registry
- Database Migration Generator
- API Contract Generator
- Frontend Screen Generator
- Test Generator
- Evidence Auto-Linking
- Human Approval Workflow
- Production Environment Profile

## Consequences

AIRA can now represent enterprise application generation as a governed capability. Human approval, evidence, security, production profile, and fail-closed release readiness remain mandatory.
